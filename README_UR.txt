CRYPTO SIGNAL PRO - ANDROID PROJECT

Is ZIP mein Android Studio project, aapki HTML signal screen aur Firebase Android config shamil hain.
Package: com.cryptosignalpro.app
Firebase project: crypto-signal-pro-3f970

AHAM HAQEEQAT:
- Yeh Android Studio source project hai, installable APK nahi.
- Is environment mein Android SDK/Gradle build tools maujood nahi, is liye yahan se APK compile nahi ho saka.
- FCM receive service tayyar hai, lekin app band hone par real trading signal bhejne ke liye alag cloud backend/monitoring function deploy karna zaroori hai. Sirf google-services.json se notifications khud-ba-khud generate nahi hotin.
- Binance public API/Internet required.
- Signal strategy educational hai; profit/accuracy guarantee nahi.

BUILD:
Android Studio mein is folder ko open karein, Gradle sync karein, phir Build > Build APK(s).
Android Studio/Gradle ko internet chahiye ho sakta hai.
